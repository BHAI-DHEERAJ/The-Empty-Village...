# सूना गाँव · Satrod Kalan, HR

**आख़िरी सिग्नल** — पंद्रह साल बाद कृष (Krish) अपनी **CRETA** में सातरोड कलां लौटता है। दादा की चिट्ठी कहती है: **“अगर गाँव की बत्तियाँ बुझी हों, तो स्कूल से मदद माँगना।”** पात्र और घटनाएँ काल्पनिक हैं।

## कैसे खेलें

Node.js 20.19+ या 22.12+ और WebGL 2 वाला ब्राउज़र चाहिए।

```sh
npm ci
npm run dev
```

टर्मिनल में दिखा **Local** लिंक ब्राउज़र में खोलो। GitHub का फ़ाइल व्यू या डाउनलोड की हुई `index.html` सीधे खोलने से गेम नहीं चलेगा।

मेनू से **New Game** शुरू करो, या **Continue** से पिछली मिशन प्रगति पर लौटो। **Settings** में रोशनी, माउस, मोबाइल कंट्रोल और डराने वाले पल बदल सकते हो। बटनों की सूची वहीं **कंट्रोल** में है। **Sound off** से शुरुआत ख़ामोशी में होती है। खेल के दौरान **Settings → Main Menu** से मेनू पर लौट सकते हो।

जंगल की सड़क पर 60 सेकंड के सफ़र और छोटी मरम्मत के बाद तुम्हें कंट्रोल मिलता है। ये दोनों शुरुआती दृश्य हैं, मिशन नहीं।

| बटन | क्या करता है |
| --- | --- |
| W, A, S, D या तीर | चलो |
| स्क्रीन पर माउस खींचो | इधर-उधर देखो |
| Shift / Space | दौड़ो / कूदो |
| E, वस्तु पर क्लिक या **इस्तेमाल** | दरवाज़ा खोलो, सुराग पढ़ो या उपकरण चलाओ |
| P या फ़ोन का आइकन | कैमरा, गैलरी और संपर्क |
| J या डायरी का आइकन | पाँच मिशन, मिले हुए सुराग और रिंच की स्थिति |
| M या लाइव नक्शे पर टैप | पूरे गाँव का नक्शा खोलो या बंद करो |
| F या टॉर्च का आइकन | टॉर्च चालू या बंद करो |

फ़ोन घुमाने पर लेआउट अपने-आप लैंडस्केप में बदलता है; पोर्ट्रेट भी चलता है। बाईं जॉयस्टिक से चलो और खाली स्क्रीन पर उँगली खिसकाकर देखो। **टॉर्च** और **फ़ोन** जॉयस्टिक के पास हैं। दाईं ओर **दौड़ो** दबाए रखो या **कूदो** दबाओ। नज़दीक से चमकती वस्तु या दरवाज़े की तरफ़ देखने पर **इस्तेमाल** बटन सुनहरा हो जाता है।

## पाँच मिशन

1. **मुख्य गली:** दादा के घर में लाल डायरी पढ़ो।
2. **पश्चिम का जंगल:** बारिश वाली झोपड़ी में नोटबुक ढूँढो।
3. **नहर पार:** पुल से खेतों तक जाओ और खलिहान की तस्वीर देखो।
4. **स्कूल:** गलियारे में मीरा का टेप चलाओ या संदेश पढ़ो।
5. **पुरानी बस्ती और हवेली:** रेडियो से मदद माँगो। संदेश पहुँचते ही कृष रेडियो पर रखा **रिंच** उठा लेता है।

**आख़िरी सफ़र:** गिनती **05 / 05** ही रहती है। नक्शे की हरी राह से CRETA तक लौटो। गाड़ी दिखते ही उसके बोनट पर छोटा **CRETA** निशान दिखेगा। सामने से बोनट की ओर देखकर **E** दबाओ, उस पर क्लिक करो, या मोबाइल पर **रिंच लगाओ** टैप करो। रिंच से मरम्मत के बाद अपने-आप पीछा शुरू होता है: पाँच किस्मों की 1,200 परछाइयाँ दौड़ती हैं और CRETA पेड़ से टकराकर रुकती है। इंजन दोबारा चालू होने के बाद कृष **20 सेकंड** तक जंगल की राह पर भागता है, हेडलाइट में आए साये से बचता है और एक नीची टहनी से टकराता है। फिर वह सुबह के राजमार्ग पर चलती गाड़ियों के बीच जा मिलता है, जहाँ ढाबे के पास लोग पैदल चल रहे हैं। अंतिम स्क्रीन से **मुख्य मेनू** पर लौट सकते हो। **Continue** रिंच और अंतिम सफ़र की प्रगति भी याद रखता है।

**फ़ोन चीट:** गाँव में खेलते समय कृष का फ़ोन खोलो → **डायल** → `123450` → **कॉल करो**। पाँचों मिशन पूरे हो जाते हैं और रिंच मिल जाता है। चीट तुम्हारी जगह नहीं बदलती और भागने का दृश्य नहीं छोड़ती: फ़ोन बंद करो, CRETA तक लौटो और बोनट पर रिंच इस्तेमाल करो।

लाइव 2D नक्शा तुम्हारे साथ चलता है। सफ़ेद निशान बताता है कि तुम किस ओर देख रहे हो, हरी लकीर मिशन की राह है और सुनहरा निशान लक्ष्य है। पूरा रास्ता और मिशन के निर्देश देखने के लिए छोटे नक्शे पर टैप करो। डायरी में भी निर्देश हैं। राह गलियों, पुलों और दरवाज़ों से होकर जाती है। पाँचवें मिशन के बाद सुनहरी कार का निशान CRETA की जगह दिखाता है।

जिस चीज़ की ज़रूरत है, उसी की 3D सतह पर सुनहरी चमक दिखती है। दीवार के आर-पार कोई डॉट नहीं दिखता। बाकी घरों में भी सुराग पढ़ सकते हो; वे अलग मिशन नहीं हैं। फ़ोन, स्कूल का मैदान, चाय की दुकान और गाँव के साये भी खुले हैं।

**रेडियो:** कार का शुरुआती सफ़र, आख़िरी पीछा और चाय की दुकान का रेडियो अपलोड किया हुआ `src/Teri Ramjhol Pari - Masoom Sharma.mp3` बजाते हैं। गाड़ी में गाना अपने-आप बजता है जब गेम की आवाज़ चालू हो। चाय की दुकान में अलग **प्ले** कंट्रोल है। बाहर से गाना स्ट्रीम नहीं होता।

### Development

- `src/game/story/VillageChapter.js`: पाँच मिशन, रिंच और स्थानीय सेव। `InvestigationProps.js`: घरों के 3D सुराग और उपकरण। `CretaFinale.js`: मरम्मत और वापसी की सड़क।
- `src/game/interaction/MissionGuide.js`: जुड़े रास्तों और दरवाज़ों से गुज़रता लाइव मिशन रूट। `src/ui/VillageMap.js`: उसी रूट और गाँव की असली बनावट से 2D नक्शा।
- `src/game/interaction/MissionHighlight.js`: उसी वस्तु की सुनहरी रोशनी।
- `src/game/watcher/`: स्टॉकर और गाँव में दिखने वाली टेक्सचर वाली परछाइयाँ।
- [HOUSES.md](HOUSES.md): गाँव के इलाक़े और घर। [Texture credits](src/assets/textures/README.md): स्थानीय टेक्सचर।

`npm test` से जाँच चलाओ।

### Hosting the game

```sh
npm ci
npm run build
npm run preview
```

`npm run preview` serves the built game locally. To publish it, serve the **entire `dist/` folder** over HTTP(S), including its `assets/` folder. For GitHub Pages, build with Vite in a Pages workflow and publish `dist/` as the Pages artifact instead of selecting the source folder as the site. The build uses relative asset paths for sites hosted under a repository subpath.
